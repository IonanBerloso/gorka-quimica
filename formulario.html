T1 Conceptos generales

Mol y masa: $\;n = \dfrac{m}{M_m}$  (M en g/mol)

Número de partículas: $\;N = n \cdot N_A$

Composición centesimal: $\;\%X = \dfrac{n_X\,M_X}{M_{compuesto}}\cdot 100$

Riqueza: $\;m_{puro} = m_{muestra}\cdot \dfrac{\%}{100}$

T2 Estructura atómica

Energía del fotón: $\;E = h\nu = \dfrac{hc}{\lambda}$

Bohr (átomos hidrogenoides): $\;E_n = -2{,}18\cdot 10^{-18}\,\dfrac{Z^2}{n^2}\ \text{J}$

De Broglie: $\;\lambda = \dfrac{h}{m\,v}$

Heisenberg: $\;\Delta x\,\Delta p \geq \dfrac{h}{4\pi}$

Números cuánticos: $n,\ \ell\in[0,n-1],\ m_\ell\in[-\ell,\ell],\ m_s=\pm\tfrac12$

T3 Enlace químico

Iónico — energía reticular (Born-Landé):

$$U=-\dfrac{N_A\,M\,z^+z^-e^2}{4\pi\varepsilon_0\,r_0}\!\left(1-\dfrac{1}{n}\right)$$

Ciclo de Born-Haber: $\Delta H_f = \Delta H_{sub} + \tfrac12 D + EI + AE + U$

Covalente — momento dipolar: $\;\mu = q\cdot d$ (debyes)

Intermoleculares: London < dipolo-dipolo < puente de hidrógeno

T4 Estados de la materia

Gas ideal: $\;pV = nRT$

Densidad de gas: $\;\rho = \dfrac{p\,M_m}{RT}$

Mezclas: $\;p_i = x_i\,p_{tot}$  (Dalton)

Boyle: $p_1V_1 = p_2V_2$  (T cte)

Charles: $V_1/T_1 = V_2/T_2$  (p cte)

Cambio de estado: $\;Q = n\,\Delta H_{transición}$

Curva de calentamiento: $Q_{sensible} = m\,c\,\Delta T$ + $Q_{latente} = n\,\Delta H_{trans}$

T5 Termodinámica

1ª Ley: $\;\Delta U = Q + W$

Trabajo (gas):

  • Isobárico: $W = -p\,\Delta V$
  • Isotermo rev.: $W = -nRT\ln(V_2/V_1)$
  • Isocoro: $W = 0$

Calor: $\;Q = m\,c\,\Delta T = n\,C\,\Delta T$

Mayer (gas ideal): $\;C_p - C_V = R$

Entalpía: $\;H = U + pV$, $\Delta H = Q_p$

Relación: $\;\Delta H = \Delta U + \Delta n_{gas}\,RT$

Adiabático: $\;pV^\gamma = $ cte, con $\gamma = C_p/C_V$

T6 Termoquímica

Entalpía de reacción estándar:

$$\Delta H^\circ_r = \sum n_p\,\Delta H^\circ_{f,p} - \sum n_r\,\Delta H^\circ_{f,r}$$

Ley de Hess: $\Delta H$ es función de estado.

Combustión: $C_xH_y + O_2 \to CO_2 + H_2O$ con $\Delta H_c < 0$

Variación con T (Kirchhoff):

$$\Delta H(T_2) = \Delta H(T_1) + \int_{T_1}^{T_2}\!\Delta C_p\,dT$$

Bomba calorimétrica: $\;Q_{liberado} = (m_{agua}c_{agua}+C_{cal})\,\Delta T$

T7 Espontaneidad · Gibbs

Entropía (Clausius): $\;\Delta S = \dfrac{Q_{rev}}{T}$

2ª Ley: $\;\Delta S_{universo} \geq 0$

Entropía de reacción:

$$\Delta S^\circ_r = \sum n_p\,S^\circ_p - \sum n_r\,S^\circ_r$$

Energía libre de Gibbs: $\;G = H - TS$

$$\Delta G = \Delta H - T\Delta S$$

Criterio:

  • $\Delta G < 0$: espontáneo
  • $\Delta G = 0$: equilibrio
  • $\Delta G > 0$: no espontáneo

Temperatura crítica: $T = \Delta H/\Delta S$  (cambio de espontaneidad)

T8 Cinética · Equilibrio

Velocidad: $\;v = k\,[A]^a[B]^b$

Arrhenius: $\;k = A\,e^{-E_a/RT}$

Equilibrio (concentraciones):

$$K_c = \dfrac{[C]^c[D]^d}{[A]^a[B]^b}$$

Equilibrio (presiones): $\;K_p = K_c(RT)^{\Delta n}$

Cociente de reacción $Q$: si $Q < K$ → →, $Q > K$ ← ←, $Q = K$ equilibrio.

Le Châtelier: el equilibrio responde oponiéndose a la perturbación (presión, concentración, temperatura).

Van't Hoff: $\;\ln\!\dfrac{K_2}{K_1} = -\dfrac{\Delta H^\circ}{R}\!\left(\dfrac{1}{T_2}-\dfrac{1}{T_1}\right)$

T9 Equilibrio ácido-base

pH: $\;pH = -\log[H_3O^+]$, $\;pOH = -\log[OH^-]$

Producto iónico: $\;K_w = [H_3O^+][OH^-] = 10^{-14}$ (25 °C)

$\;pH + pOH = 14$

Ácido débil HA: $\;K_a = \dfrac{[H_3O^+][A^-]}{[HA]}$, $\;pK_a = -\log K_a$

Base débil B: $\;K_b = \dfrac{[BH^+][OH^-]}{[B]}$

Pares conjugados: $\;K_a\cdot K_b = K_w \implies pK_a + pK_b = 14$

Ácido fuerte: $\;[H_3O^+] = c_0$  ($\alpha = 1$)

Ácido débil: $\;[H_3O^+] \approx \sqrt{K_a\,c_0}$ (si $\alpha < 5\%$)

Henderson-Hasselbalch (tampón):

$$pH = pK_a + \log\!\dfrac{[A^-]}{[HA]}$$

Punto de equivalencia (valoración):

$$n_{ácido} = n_{base}\Rightarrow V_a c_a = V_b c_b$$
